How It Works

1

Data Collection

ESP32 reads temperature and humidity data every 60 seconds.

  • • BME280 sensor (I2C)
  • • TFT display for local view
  • • WiFi connectivity
2

Cloud Ingestion

Data is sent securely to AWS IoT Core via MQTT over TLS.

  • • Encrypted transmission
  • • Certificate-based auth
  • • Topic: weather/data
3

ML Prediction

Lambda function runs physics-based model to predict next 10 hours.

  • • Diurnal temperature curve
  • • Humidity inverse correlation
  • • Rain probability calculation
4

Data Storage

Current and forecast data stored in DynamoDB for fast retrieval.

  • • Partition key: device_id
  • • Sort key: timestamp
  • • JSON forecast data
5

API Exposure

API Gateway provides HTTP endpoint for dashboard queries.

  • • GET /weather endpoint
  • • CORS enabled
  • • Lambda integration
6

Visualization

React dashboard displays live data with animated weather effects.

  • • Animated clouds & sun
  • • 10-hour forecast table
  • • Auto-refresh every 5s
